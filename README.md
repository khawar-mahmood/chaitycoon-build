# Chai Tycoon

Run a roadside chai stall and grow it into a busy dhaba: brew chai, cook parathas and fry samosas, serve the
queues, rickshaw drivers and dining guests, and hire cooks and helpers as you grow.

**Play in your browser:** https://khawar-mahmood.github.io/chaitycoon-build/

Controls: drag anywhere (touch or mouse) or use WASD to walk.

This repository holds only the playable WebGL build.
